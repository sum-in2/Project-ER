## 게임 규칙

### 실험체 (플레이어블 캐릭터)

```
기본 스킬 구성:
- 액티브 스킬 1~4개
- 패시브 스킬 1개

캐릭터별 스킬 데이터는 CharacterData(SO)에서 관리 예정
```

### 조작법 (기본값, 추후 설정에서 리바인딩 가능)

```
마우스 우클릭 (컨텍스트별 동작):
- 빈 공간 클릭          → 이동 (NavMesh 클릭투무브)
- 상호작용 가능 오브젝트 → 상호작용
- 공격 가능 대상         → 공격

키보드:
Q / W / E / R  → 액티브 스킬 1~4
T              → 패시브 스킬
D              → 무기 스킬
F              → 전술 스킬
`              → 휴식
```

### 설계 메모

- 조작법은 하드코딩 금지 → 추후 설정(키 리바인딩) 시스템에서 변경 가능하도록 New Input System의 Input Action Asset / 바인딩 오버라이드 활용 고려
- 우클릭 동작 분기는 Raycast 결과의 대상 타입(IInteractable / IDamageable / 지형)에 따라 다형성으로 처리 (`if/else` 타입 분기 지양)
